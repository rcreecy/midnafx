# MidnaFX

MidnaFX is an experimental native visual processing mod for Dusklight. M2 adds a fused
pre-HUD grading shader with exposure, black point, contrast, gamma, saturation, highlight
rolloff, temperature and tint controls. Neutral grading bypasses the render pass. A forced
RGBA passthrough remains available for validating the M1 render path. Presets and
automatic Twilight profiles are later milestones. Windows builds have not been tested in
the game; Intel Mac/Metal validation is still required.
