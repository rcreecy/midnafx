MidnaFX 0.9.2 tightens the safety boundary of the opt-in modern exploration camera.

The source-matched Dusklight host patch now rejects FOV and lower-angle changes as soon
as TP reports attention lock, a lock-on target, or active L-lock state. This closes a
case where target framing could briefly retain exploration-camera modifiers before the
native camera changed mode. Live Windows D3D12 testing confirmed immediate native
fallback while holding the target control; a spawned enemy also exercised the native
mode-1 path. A stable mode-2 enemy lock remains an explicit validation item.

This release also records completed visual passes for active Twilight, dark interiors,
night lighting, and controller-driven camera movement. The temporary validation input
harness was removed before the release build. The clean source-matched Windows host
build and all 10 portable tests passed.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
