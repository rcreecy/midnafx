MidnaFX 1.18.0 extends experimental **Local light response** to the default native
lantern channel. Its current position, color and fading reference power feed the
existing four-source illumination pipeline. Remaster and the independent Basic
control retain 15% strength; no new setting or saved-look migration is needed.

The lantern uses the native steep GX distance polynomial, rather than treating
reference distance as a radius. A separate one-percent-response trace envelope
is capped at 6,000 world units and fades across its last quarter. Current active
state is required every frame; inactive slot contents are never reused.

Only alpha-255, omnidirectional, steep-distance player sources are supported.
Other spotlight modes and boss slots remain excluded. Ordinary point lights,
visibility, energy/headroom limits and scene alpha retain their existing behavior.
No rendering pass, target, history or host patch is added.

Portable coefficient checks, 87 GPU cases and controlled native moving/fading/
inactive source phases pass, followed by reload and normal shutdown. The native
fixture does not equip a lantern or establish equipped-lantern gameplay, broad
art/motion quality or GPU performance.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
remains unverified and support stays best effort through native builds and
portable checks. See [feature and evidence notes](https://github.com/rcreecy/midnafx/blob/v1.18.0/docs/local-lighting.md#player-lantern-source).
