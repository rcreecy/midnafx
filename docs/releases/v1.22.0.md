MidnaFX 1.22.0 brings the Remaster scene effects to default settings. Unset
controls enable contact shading, contact shadows, color bounce, local lights,
sunlight shafts, depth atmosphere, adaptive exposure, bloom and water reflections
at existing Remaster strengths. Saved settings take priority. Select **Vanilla**
for original presentation.

**Material relighting** evaluates supported lit surfaces per pixel using their
native lights and normals. It defaults on with the optional patched Dusklight
host. Stock Dusklight uses its native material renderer with MidnaFX scene
effects. The host patches and setup are in the source release.
[Material relighting setup](https://github.com/rcreecy/midnafx/blob/v1.22.0/docs/material-relighting.md)

Windows development trials covered original and replacement textures, shader
warmup fallback, toggling, live reload and normal shutdown. Intel macOS support
is best effort through package builds and portable checks. Whole-game rendering
quality and GPU cost remain unqualified.
[Windows evidence](https://github.com/rcreecy/midnafx/tree/v1.22.0/docs/evidence/material-relighting-2026-11-03)

The source release also includes a read-only catalog tool for models, materials
and textures across nested game archives.
[Asset catalog](https://github.com/rcreecy/midnafx/blob/v1.22.0/docs/asset-awareness.md)
