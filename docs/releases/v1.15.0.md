MidnaFX 1.15.0 upgrades **Enhanced model shading**, the existing independent Basic
control. Qualified rigid models can improve safe normal regions while retaining
uncertain seams and shared normal indices unchanged. It remains opt-in; Remaster
does not enable it automatically. No new asset allowlists are added.

Enabling the control now visits eligible resident model archives without loading
resources or taking references. The sweep resumes between models, with no
recurring topology scan after completion. Automatic qualification requires opaque
materials, rigid matrices, original bounded draw data and complete load history.
After reloading MidnaFX, restart the game for automatic coverage; cached scene
resets may retain old resources.

Before native deformation attaches, MidnaFX restores its rigid normals and
excludes that model-data generation. Disable, archive deletion and unload restore
only normal records still matching MidnaFX's applied bytes, preserving detectable
intervening writers. Original/applied backups share a 16 MiB limit. Strict
topology defaults and the independent supported-Link contract remain unchanged.

The generic path changes normal shading, not silhouettes, positions, UVs, skin
weights or indices. Existing validated rebuilds remain separate legacy behavior.
No GPU pass is added. Broad art, motion, deformation compatibility and universal
performance remain unqualified; the control deliberately stays opt-in.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
remains unverified and support stays best effort through native builds and
portable checks. See [feature and evidence
notes](https://github.com/rcreecy/midnafx/blob/v1.15.0/docs/model-shading.md).
