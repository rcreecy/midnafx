MidnaFX 1.4.0 adds **Enhanced Link shading** to Basic controls and the
**Remaster** profile. It conservatively improves lighting continuity on supported
regions of Link's original casual outfit. Selecting Vanilla or disabling the
control restores the original normal bytes. Existing installations retain their
saved settings until a profile is selected or the control is enabled.

The feature preserves material boundaries, authored normal splits, conflicting
shared indices and uncertain face orientations. It activates on a resident
supported model without requiring a scene reload. Other outfits, characters and
replacement models remain unchanged. It does not add polygons or change the
silhouette, skin weights, animation or texture coordinates.

Windows D3D12 Ordon evidence shows 297 changed normals, 1,402 preserved indices
and exact restoration of all 13,692 original normal bytes. A matched frozen scene
changes 1,469 pixels above a three-level threshold, all inside Link's region;
sampled scenery is identical. This is a subtle, localized shading improvement.
Broader artistic and motion review remain open. The Windows suite passes all
22 tests, including strict rejection and conservative-preservation regressions.

Windows x64 and Intel macOS x86_64 packages are separate. macOS support remains
best effort: CI builds the package and runs portable checks. Native Mac gameplay
and Metal execution are unverified. No game assets or third-party texture packs
are included. The shading feature requires the supported original model and the
native hook interfaces provided by compatible Dusklight builds.
