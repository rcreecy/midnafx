MidnaFX 0.9.0 adds a default-off depth-of-field blur prototype.

The new path separates near and far scene color at half resolution, applies a
separable Gaussian blur, and composites against full-resolution depth before the
HUD. It supports manual focus distance and camera-target autofocus. Camera-target
focus requires the source-matched CameraService 1.4 host extension and fails
closed when unavailable.

Source-matched Windows D3D11 testing confirmed that both compute and composite
callbacks execute without MidnaFX, WebGPU, or validation errors. A default-off
run submitted no blur work. Native CI covers Windows and Intel macOS builds,
tests, shader compilation, and packaging.

This feature remains experimental and disabled by default. Matched visual
quality captures, Intel Mac/Metal runtime validation, resize testing, and broad
gameplay tuning remain deferred.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
