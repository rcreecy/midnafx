MidnaFX 0.7.1 adds **Natural / Vivid Realism**, a built-in gameplay grading preset.

Enable grading, then choose **Natural / Vivid Realism** under **Current preset**.
The look combines restrained saturation, neutral whites, a gentle midtone lift,
softer highlights, and subtle detail enhancement. Save or Duplicate creates an
editable copy; Vanilla restores neutral grading.

The preset uses the existing pre-HUD shader. It does not add lighting or materials.
Detail uses five scene samples per pixel; disable detail if needed for performance.
Existing presets remain compatible. Camera features from 0.7.0 remain opt-in.

Native CI checks cover packaging, shader compilation, preset serialization, and
tonal behavior. In-game visual evaluation of this preset and Intel Mac/Metal runtime
validation remain outstanding; build success is not proof of perceptual realism.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
