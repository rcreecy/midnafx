MidnaFX 1.0.0 is the first complete release of the project's modern visual
foundation for Twilight Princess on Dusklight.

The release includes pre-HUD color grading and detail enhancement, built-in
Natural / Vivid Realism and Twilight profiles, an opt-in wider and lower
exploration camera, and exact-allowlist adaptive normal smoothing. Camera
modifiers fail closed during authored views, first person, aiming, lock-on,
boss-special cameras, and detached-camera ownership. Live Windows testing
includes movement, combat, Fyrus, stage changes, toggles, mod unload, and normal
camera recovery.

Depth reconstruction and depth of field remain experimental and default off.
The depth-of-field quality pass adds a 2-12 pixel blur-radius control, smooth
camera-target autofocus, and near-layer compositing that avoids spreading blur
across in-focus silhouettes. Geometry smoothing also remains default off and
processes only exact validated resource fingerprints; unsupported or ambiguous
models are left unchanged.

Windows D3D12 runtime validation covered the final combined grading, detail,
camera, depth-of-field, and static-geometry path at 1216x896. The package passed
all 13 deterministic tests, Dawn shader compilation, restoration checks, and
clean shutdown. Windows and Intel macOS packages are built by CI.

Known limits: live Intel Mac/Metal execution and GPU timing are still
unvalidated. The revised depth-of-field silhouette behavior has source-matched
runtime execution proof but no new matched screenshot from the final automation
session. Native environment overrides, global geometry smoothing, subdivision,
material replacement, and additional model allowlists remain future work.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
