MidnaFX 1.7.0 adds **Scene bloom** across scenery, characters and replacement
textures without asset allowlists. Bright scene pixels receive restrained,
resolution-scaled glow. Select **Profile / Remaster** or enable the independent
Basic control; strength defaults to 20%. **Vanilla** disables it. Existing settings
remain intact until a profile is selected.

Quarter-resolution highlight extraction and two filters feed the existing
grading/water draw. Bloom preserves alpha and the white endpoint, composes with
adaptive exposure, AA, detail and LUTs, and leaves the native HUD downstream.
Resize resources follow queued callbacks; unavailable bloom retains the original
lighting while other effects remain usable.

This is LDR highlight bloom, not HDR, emissive classification or new dynamic
lighting. Bright non-emissive surfaces can glow. Focused GPU checks and native
Windows Ordon toggle/resize/reload/close checks pass. A separate Goron Mines
startup remained black before bloom dispatch; its cause is unresolved. Whole-game
art/motion quality and GPU timing remain open.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
and Metal execution remain unverified; support is best effort. No game assets or
third-party texture payloads ship. See [the feature notes](https://github.com/rcreecy/midnafx/blob/v1.7.0/docs/scene-bloom.md).
