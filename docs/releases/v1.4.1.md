MidnaFX 1.4.1 extends **Enhanced Link shading** to Link's original **Hero's
Clothes**, alongside the Ordon outfit introduced in 1.4.0. It works through the
existing Basic control and Remaster profile. Existing saved settings remain
unchanged; select Remaster or enable the control to use the effect.

The standard outfit uses the original normal indices and mesh. Compatible regions
receive a restrained blend toward their geometric smoothing groups; conflicting
shared indices retain their authored values. Native Windows D3D12 outfit switching
loads and applies the supported standard body with 194 changed normals and 1,044
preserved indices. A frozen-scene comparison records a subtle character shading
change while sampled scenery remains identical.

Disabling the effect restores the original normal bytes. It does not change
polygons, skin weights, animation, UVs or silhouettes. Armor outfits, other
characters and replacement models remain outside the supported identities.
Character identity hashing now reuses one result during qualification and logging.
Supported characters derive their smoothing plan from fingerprinted original
draw lists, repairing re-enable when native runtime draw copies have changed.

Windows x64 and Intel macOS x86_64 packages are provided separately. macOS remains
best effort: package builds and portable checks run in CI; native gameplay and
Metal execution remain unverified. No game assets or texture packs are included.
