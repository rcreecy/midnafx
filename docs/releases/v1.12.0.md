MidnaFX 1.12.0 adds **Motion clarity** across gameplay contexts, reducing native
previous-frame blending without asset or stage lists. Select **Profile /
Remaster** or the independent Basic toggle. Advanced: motion offers 0–100%
retained native blend alpha, defaulting to 0%. **Vanilla** disables the feature.
Existing saved settings remain intact until a profile is selected.

Native event, demo-camera, pause and fade contexts retain their original blur.
The mod borrows only the blur-rate byte after opaque rendering and restores it
before HUD rendering. Native enable flags, history state, matrices and framebuffer
copies remain under game ownership; detectable intervening writes are preserved.
Pending ownership also recovers at the next scene or module unload.

Exhaustive rate/rounding, safety-gate and write-ownership checks pass. A temporary
native request fixture distinguishes eligible gameplay reduction from real
conversation-event bypass and verifies restoration at the HUD boundary. The
fixture does not ship. Broad motion comfort and every authored effect remain
unqualified. Combat effects that use this native blend are also reduced during
eligible gameplay; turn the independent control off to preserve them.

No shader pass, render target or new host patch is added. Native zero-alpha blend
draws may still execute, so no GPU speedup is promised. Windows x64 and Intel
macOS x86_64 packages are supplied separately. Mac gameplay remains unverified
and support stays best effort. See [feature and evidence
notes](https://github.com/rcreecy/midnafx/blob/v1.12.0/docs/motion-clarity.md).
