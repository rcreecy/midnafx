MidnaFX 1.8.0 upgrades scene anti-aliasing with a shared edge-directed spatial
filter. Bounded endpoint searches smooth stair steps while preserving aligned
edges and tested fine lines. The existing **Anti-aliasing (experimental)** switch,
default-on behavior and Remaster/Vanilla controls remain unchanged.

The new filter reduces shallow-edge coverage error by about 70% against the old
five-tap filter in fixed supersampled fixtures. It preserves tested one-pixel
lines, checkerboards, isolated pixels, alpha and ordinary/water composition.
Those synthetic results are not a guarantee for every edge or gameplay motion.
Native Windows on/off, combined Remaster reload and normal close checks pass.

No new render target, pass, binding or host patch is required. Edge sampling cost
increases; GPU duration and 4K performance remain unmeasured. This remains spatial
AA, without temporal reconstruction or complete texture-shimmer removal.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
and Metal execution remain unverified; support stays best effort. No game assets
or third-party texture payloads ship. See [feature and evidence notes](https://github.com/rcreecy/midnafx/blob/v1.8.0/docs/edge-antialiasing.md).
