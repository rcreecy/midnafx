MidnaFX 1.11.0 adds **Screen-space color bounce (experimental)** across visible
opaque scenery and characters. Nearby facing surfaces contribute restrained
color using native scene color and depth, without asset or stage lists. Select
**Profile / Remaster** or enable the independent Basic toggle; Advanced lighting
strength defaults to 12%, with a 0–30% range. **Vanilla** disables it. Existing
saved settings remain intact until a profile is selected.

Sixteen nearby surface samples feed a half-resolution color field, with facing,
range, depth visibility and surface-aware filtering. A bounded linear-light
blend precedes independent atmosphere, preserving alpha and downstream water/HUD
ordering. The effect shares the existing opaque snapshot and composition. With
contact shading already active, bounce adds one gather dispatch and two
half-resolution color textures; standalone bounce also runs the shared geometry,
filtering and composition work.

Thirty-two deterministic GPU cases pass. Native Windows toggles, Remaster
integration, resize, module reload and normal close pass. Repeated unchanged
native screenshots still vary, so they do not establish an isolated visual-quality
comparison; that limitation remains recorded with the original captures.

This supplements native lighting with one bounded screen-space approximation.
Source colors already contain native lighting and fog; material albedo, hidden
surfaces, emissive classification and complete global illumination are
unavailable. Broad camera-motion/art quality and GPU duration remain open.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
and Metal execution remain unverified; support stays best effort. No game assets
or third-party texture payloads ship. See [feature and evidence
notes](https://github.com/rcreecy/midnafx/blob/v1.11.0/docs/color-bounce.md).
