MidnaFX 1.3.0 adds a one-click **Profile / Remaster** at the top of settings.
It combines natural grading, detail, modern exploration FOV, anti-aliasing,
enhanced water, ambient contact shading and depth atmosphere. **Vanilla**
disables these profile effects together. Existing configurations retain their
settings until a profile is selected; individual controls remain available.

Ambient occlusion adds contact and crease shading across opaque scenery and
characters. Depth atmosphere follows the game's current fog palette and range,
with adjustable strength. Both share one depth-aware draw before later
translucent rendering and the HUD. Atmosphere bypasses underwater camera views,
paused game menus and unavailable world/fog inputs. Unsupported graphics layouts
retain their original rendering.

The release also includes the default-off warm pumpkin material profile and
repairs for cached material binding and resource lifetime handling developed
since 1.2.0. New saved profiles retain scene-effect switches; older formats
remain readable. Camera, water and atmosphere tuning stay independent of saved
profile switches.

Windows validation includes shader compilation, preset persistence, offscreen
GPU regression checks and native D3D12 Ordon comparisons. AO has native reload
and clean shutdown evidence. These are incremental rendering improvements,
not a completed remaster, dynamic lighting, normal mapping or new mesh geometry.
Broad scene/motion quality and high-resolution GPU performance remain open.

Windows x64 and Intel macOS x86_64 packages are provided separately. macOS support
is best effort: native package and portable checks run in CI; native Mac gameplay
and Metal execution are unverified for this release. No hosted Metal execution
is required. Third-party texture packs and game assets are not included.
