MidnaFX 1.6.0 upgrades ambient contact shading across opaque scenery and
characters. A 32-tap half-resolution field replaces the former 16-tap kernel,
with surface-aware filtering and edge-aware reconstruction for smoother contacts.
It uses the existing **Ambient occlusion** control and **Profile / Remaster**.
No asset-specific configuration is required.

The renderer keeps native full-precision depth, preserves alpha and native
translucent/water/HUD ordering, and scales the radius cap with resolution. It
uses no temporal history or jitter. Resize retirement follows queued callbacks,
and unavailable AO preserves the independent depth-atmosphere effect.

Focused GPU checks cover contacts, filtering, depth isolation, fog fallback,
alpha and small/odd dimensions. Native Windows checks cover visible scene
shading and lifecycle behavior. Whole-game motion quality and GPU duration remain
open; half resolution can miss thin contacts. Windows x64 and Intel macOS x86_64
packages are supplied separately. Mac gameplay/Metal remain unverified and
support stays best effort. No game assets or third-party texture payloads ship.
