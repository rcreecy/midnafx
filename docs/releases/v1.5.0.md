MidnaFX 1.5.0 adds **Adaptive exposure** across the entire scene. It gradually
improves dark-view readability and restrains bright views, affecting scenery,
characters and replacement textures through one shared rendering path.

Select **Profile / Remaster** or enable **Adaptive exposure** in Basic. It works
with grading off. **Vanilla** disables it, and existing settings are retained
until a profile is selected. No per-asset configuration is needed.

Correction is bounded to -0.5 through +0.75 stops to retain authored lighting and
night/dungeon mood. Brightening preserves black/white endpoints and color ratios;
alpha stays unchanged. History resets across room/stage/layout changes, pauses and reloads.
The 256-sample GPU meter reuses the existing scene snapshot and grading/water
draw, with no CPU readback or extra fullscreen pass.

Windows checks cover GPU adaptation/composition and native day/night toggles.
Broader dungeon/combat/cutscene art evaluation and GPU duration measurement remain
open. Windows x64 and Intel macOS x86_64 packages are provided separately; macOS
remains best effort with package/portable CI checks and unverified native gameplay.
No game assets or third-party texture packs are included.
