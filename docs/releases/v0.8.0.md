MidnaFX 0.8.0 adds developer-facing depth reconstruction and depth-of-field
focus diagnostics for the next rendering milestones.

The atmosphere diagnostic visualizes reconstructed linear depth before the HUD.
The depth-of-field diagnostic classifies near, focused, far, background, and
invalid pixels with distinct colors. Both features are default-off and fail
closed when required renderer data is unavailable.

This release does not enable production fog or blur. Runtime proof covers the
source-matched D3D11 build. Native CI covers Windows and macOS builds, tests,
shader compilation, and packaging. In-game visual capture and Intel Mac/Metal
runtime validation remain deferred.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
