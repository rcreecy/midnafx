MidnaFX 0.7.0 adds the completed opt-in modern exploration camera foundation.

The candidate profile combines 110% tangent-space vertical FOV with a 6-degree
lower native chase-camera angle. Dusklight retains camera smoothing, collision,
targeting, authored scenes, and every non-chase camera controller. The host
fails closed during conversations, item events, cutscenes, detached camera use,
nonzero modes, and all camera algorithms other than native chase.

The controls remain disabled by default. They require a Dusklight build carrying
MidnaFX's CameraService 1.3 patch; older or unpatched hosts keep native framing
and report the camera feature unavailable. Windows D3D11 runtime evidence covers
matched framing, real authored-event handoff, forced ownership guards, aspect
ratios, and in-process enable/disable. Intel Mac/Metal runtime behavior remains
unvalidated.

This release retains the grading, detail, Twilight automation, diagnostics, and
conservative adaptive-normal features from 0.6.0.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
