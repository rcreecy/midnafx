MidnaFX 1.21.0 upgrades **Depth atmosphere** with sunlit outdoor haze. Distant
atmosphere receives more of the native sun's color toward its direction, while
the existing fog range, density and strength remain unchanged. Remaster and the
independent Basic control use the upgrade without new settings or migration.

The source uses native daylight alpha and full-sphere direction, including an
off-screen sun. Screen/depth-probe sprite visibility is not treated as daylight
availability. Unsupported weather, indoor, Twilight, event and invalid-source
contexts keep the original atmosphere. Existing pause, underwater and missing
world-input bypasses remain.

A bounded forward lobe blends at most half the current daylight alpha into the
fog target color. No new texture, compute dispatch, fullscreen draw, temporal
history, asset list or host patch is added. This is an LDR directional tint,
not volumetric transport, atmospheric shadowing or material relighting.

Portable source checks and 103 production GPU cases pass, including sixteen new
checks for forward bounds, off-screen continuity, fading, exact fallback, alpha,
reversed-Z and contact-lighting order. Broad art/motion quality and GPU duration
remain unqualified.

Native Windows visual, toggle, reload and normal-close checks remain unverified
because the available RDP session is disconnected and monitor capture fails.
The owned native trial is forcibly terminated for cleanup; that is not a normal
shutdown pass. Automated source and GPU checks remain the evidence for this slice.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
remains unverified and support stays best effort through native builds and
portable checks. No hosted Metal execution is required. See
[feature and evidence notes](https://github.com/rcreecy/midnafx/blob/v1.21.0/docs/depth-atmosphere.md).
