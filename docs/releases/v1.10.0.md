MidnaFX 1.10.0 adds **Movement camera framing** across exploration chase-camera
contexts. The view widens during brisk movement and returns smoothly at rest,
without asset or stage lists. Select **Profile / Remaster** or enable the
independent Basic control. **Vanilla** disables it. Existing saved settings remain
intact until a profile is selected.

Advanced camera tuning offers a 0–12% movement boost, defaulting to 8% in tangent
space. Native speed relative to the current player maximum drives the response;
the default transition expands over 0.35 seconds and settles over 0.70 seconds.
Static exploration FOV remains independently configurable. Native aiming and
authored camera contexts preserve their original framing.

Clock, envelope, invalid-input and preset compatibility checks pass. A temporary
native replay fixture exercises running and camera output on Windows D3D12.
This does not establish whole-game motion comfort or combat/cutscene coverage.
No new rendering pass or host patch is added; camera modification still requires
the existing CameraService 1.3 extension. A wider view can expose more geometry.

Windows x64 and Intel macOS x86_64 packages are supplied separately. Mac gameplay
and Metal execution remain unverified; support stays best effort. No game assets,
third-party texture payloads or validation driver ship. See [feature and evidence
notes](https://github.com/rcreecy/midnafx/blob/v1.10.0/docs/movement-camera.md).
