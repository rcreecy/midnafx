MidnaFX 0.6.0 is the first experimental release.

It adds pre-HUD scene grading, optional detail enhancement, presets, diagnostic
views, an optional automatic Twilight profile, and conservative adaptive normal
smoothing for a small exact allowlist of validated models. All features fail closed;
grading bypasses when neutral, and geometry smoothing remains disabled by default.

The Windows AMD64 package has been exercised in a source-matched Dusklight D3D11
runtime with the official US game file. The macOS x86_64 package passes its native
CI build and package tests, but Intel Mac/Metal runtime behavior and GPU performance
remain unvalidated. Automatic Twilight behavior has live coverage for normal and
active states; the Twilight-spot exclusion has deterministic test coverage only.

Install the asset matching your platform in Dusklight's mods folder:

- `midnafx-windows-amd64.dusk`
- `midnafx-macos-x86_64.dusk`
